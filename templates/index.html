RT-DETR

How RT-DETR Works

RT-DETR is a real-time object detection model designed to detect objects efficiently without requiring traditional Non-Maximum Suppression.

In this project, the trained RT-DETR model receives the uploaded image, extracts important visual features, identifies gold packets, and predicts their locations using bounding boxes.

1
Input Image Uploaded gold packet image
2
Feature Extraction Important image features are learned
3
Transformer Encoder Processes relationships between features
4
Object Detection Packets and their locations are predicted
